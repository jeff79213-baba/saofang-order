# 民宿掃房順序系統 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development。以 checkbox 追蹤。
> 規格：v1（未改處沿用）＋ `docs/superpowers/specs/2026-11-04-民宿掃房順序系統-v2-design.md`。

**Goal:** 加入自訂房號（清單式）、樓層當日自訂打掃順序、帳號管理（Cloud Function／保留區），並做 Header／卡片／標籤 UI 微調。

**Architecture:** 房間改穩定 ID（uuid）＋可編輯 `no`；自訂順序存 `sq-days/{day}/orders/{floorId}`；帳號管理由新 functions codebase `saofang` 的 callable `saofangApi` 提供，前端另立 `accounts.ts`。

**Tech Stack:** 既有 React 18 + TS + Vite + Tailwind + Firebase；新增 `firebase/functions`（client SDK）與 Cloud Functions（nodejs22）。

## Global Constraints
- 房號：**純數字 3–4 位**、**同館唯一**。
- 自訂順序：**只存當日**（換日失效）。
- 帳號：Cloud Function `saofang`（callable `saofangApi`），驗證 `sq-staff/{uid}.role=='front'` 且未 disabled/deleted。
- 集合前綴 `sq-`、localStorage `sq-`；Hosting site `saofang-sk`。
- rules 共用 opencode-sk，動前先跑漂移檢查，一律 `npm run deploy:safe`。
- 密碼欄位附顯示/隱藏切換。

**Files:** `src/lib/ordering.ts`, `src/lib/ordering.test.ts`
